# Azure DevOps Labs and CI/CD Examples

This repository contains a collection of **Azure DevOps training materials, lab exercises, and supporting documents**.  
It is designed for learning and practicing CI/CD concepts, build/release pipelines, and integrations with common DevOps tools.

## Getting Started

### Prerequisites
- An Azure DevOps organization
- Access to Azure Pipelines
- Basic knowledge of Git, CI/CD, and DevOps workflows

### How to Use
1. Open the `.pptx` files to learn key concepts of Azure DevOps.
2. Follow the step-by-step instructions in the `.docx` lab guides.
3. Apply the exercises in your own Azure DevOps environment.
4. Extend the labs by integrating with tools like:
   - Ansible for configuration management
   - Maven for Java builds
   - Docker for containerized pipelines
   - SonarQube for code quality checks


This repository can be used for:
- Self-paced Azure DevOps learning
- Corporate DevOps training
- Lab practice in workshops
- Reference for CI/CD pipeline implementations
